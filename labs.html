Faculty Laboratories

Practical sessions across all five departments are held in the Faculty's two computer laboratories. Here's what each one is used for.

Computer Laboratory 1

The Faculty's main laboratory, used mostly for introductory programming, general computer literacy classes and large-group practicals.

Typically used for:

  • Introductory programming practicals
  • Office productivity and computer appreciation classes
  • Departmental tests conducted on computers

Computer Laboratory 2

A smaller, specialised laboratory used for advanced practicals such as networking, security tools and software project work.

Typically used for:

  • Networking and systems administration practicals
  • Cyber security and ethical hacking labs
  • Final-year and group project work

Lab etiquette

  • Sign the attendance register at the start of every practical session
  • Report any faulty system to the lab technician on duty immediately
  • Do not install unauthorised software or connect personal storage devices without permission
  • Shut down systems properly at the end of each session
  • It is not permissible to eat inside the laboratory
  • All bags should be dropped at the entrance of the laboratory
